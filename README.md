# Hi, I'm Yang 👋

I'm based in Christchurch, New Zealand. My background combines full-stack engineering with master's-level study in applied AI. I'm exploring content and creative tools. I build small tools for the things I keep running into: reading AI agent logs, wiring local agents together, and seeing how far a model can go with a creative idea.

[PixelPaw Labs](https://github.com/PixelPaw-Labs) is my personal software lab for agent tooling and workflow automation.

## Trace tools

### [Claude Code Trace](https://github.com/delexw/claude-code-trace) · [380 stars](https://github.com/delexw/claude-code-trace/stargazers)

A viewer for local Claude Code session logs. It turns JSONL files into readable conversations with expandable tool calls, token counts and live tailing, and runs as a desktop app, web app or TUI. Optional Jev analysis looks at agent efficiency, and shows you the redacted payload before anything is sent. MIT licensed.

### [Codex Trace](https://github.com/PixelPaw-Labs/codex-trace) · [116 stars](https://github.com/PixelPaw-Labs/codex-trace/stargazers)

The same idea for OpenAI Codex CLI sessions: search, live tailing, tool call inspection and collaboration chains between orchestrator and worker sessions. MIT licensed.

## What I'm exploring now

**[Kiteva](https://github.com/delexw/kiteva)** is a personal creative room where an idea becomes a short motion-graphics film. I'm not a designer. I collected motion pieces I liked, along with notes on how each could be made, then built an agent to put that collection to work. It drafts a brief, proposes directions, renders short previews and builds the full film. Shared under a non-commercial license.

## Other experiments

- **[DovePaw](https://github.com/PixelPaw-Labs/DovePaw)** is an app for building, scheduling and orchestrating private Claude Code agents over A2A. It's a nights-and-weekends project, licensed MIT with Commons Clause (no commercial use).
- **[Excalibur](https://github.com/delexw/excalibur)** is a CLI that runs AI agents through proposal, critique and vote rounds until they reach consensus. MIT licensed.
- **[PixelFlow](https://github.com/PixelPaw-Labs/PixelFlow)** is a CLI for video upscaling and frame interpolation using Real-ESRGAN, RIFE and FFmpeg.

Issues and ideas are always welcome on any of these.
